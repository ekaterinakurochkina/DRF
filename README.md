# 34.2 Docker Compose

Запуск приложения

Для запуска используйте команду:
docker-compose up -d --build

Для просмотра логов всех контейнеров используйте команду:
docker-compose logs

Чтобы остановить все работающие контейнеры
и удалить контейнеры, сети, тома и образы, используйте команду:
docker-compose down -v
